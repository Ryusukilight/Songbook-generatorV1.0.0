# Songbook PDF Generator V1.0.0

A free, lightweight desktop application to quickly generate beautiful PDF songbooks from Excel data files. Developed by **Electronicsbuilds by ArnelJr**.

![App Screenshot](screenshot.png)
---

## ✨ Features
*   **Excel Integration:** Easily import your song lists directly from an `.xlsx` file.
*   **Custom Headers:** Add a Top-Left, Top-Right, Main Title, and Subtitle to personalize every page.
*   **Flexible Layouts:** Choose between 1 to 4 columns to perfectly fit your songs on the page.
*   **Custom Styling:** Adjust the font size and pick from different color themes (e.g., Green, Blue, Red) to match your style.
*   **One-Click Generation:** Instantly compile everything into a clean, printable PDF.

---

## 🚀 How to Use

1. **Download the App:** Go to the **Releases** tab on the right side of this page and download the latest `.exe` file.
2. **Prepare your Data:** Ensure your song list is formatted correctly in an Excel file (Column A for Song Title, Column B for Lyrics/Chords).
3. **Open the App:** Run the downloaded `.exe` file (No installation required).
4. **Customize:** 
   * Click **Browse...** to select your Excel file.
   * Fill in your Header Texts (Title, Subtitle, etc.).
   * Select your preferred Columns, Font Size, and Color Theme.
5. **Generate:** Click the big blue **GENERATE PDF** button and save your new songbook!
